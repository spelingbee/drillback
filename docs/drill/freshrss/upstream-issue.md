FreshRSS's backup page says what to keep, how much each item matters, what to skip and
why, and gives the commands in both directions. The drill tested both claims in its first
sentence - that the data directory is what you need, and that the cache inside it can be
skipped - and both are true.

If this drill produces one recommendation for other projects, it is to copy this page's
first four lines. Marking each item required, recommended or optional, and naming the one
directory that can be left out, is the difference between a backup page and a backup page
somebody can act on.
